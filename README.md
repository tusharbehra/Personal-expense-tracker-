# Personal Expense Tracker

A simple Python-based console application for recording and analyzing personal expenses.

## Project Objective

The objective of this project is to create a simple expense tracking system using basic Python programming concepts such as lists, dictionaries, functions, loops, conditional statements, input validation, and basic algorithms.

## Features

The application provides the following features:

1. **Add Expense**

   * Enter the name and amount of an expense.
   * The expense is stored in the program.
2. **View Expenses**

   * Displays all recorded expenses with their amounts.
3. **Delete Expense**

   * Allows the user to remove a selected expense.
4. **Total Expense**

   * Calculates the total amount spent.
5. **Highest Expense**

   * Finds and displays the expense with the highest amount.
6. **Number of Expenses**

   * Displays the total number of recorded expenses.
7. **Expense Summary**

   * Displays the number of expenses, total expense, and highest expense together.
8. **Clear All Expenses**

   * Removes all recorded expenses after confirmation.

## Program Structure

The project is divided into three main functional modules:

### 1\. Expense Management

Handles adding, viewing, and deleting expenses.

### 2\. Expense Analysis

Calculates total expenses, finds the highest expense, counts expenses, and generates a summary.

### 3\. Data Management

Provides the option to clear all stored expenses.

## How to Run

1. Install Python 3 on your computer.
2. Save the program as:

```text
expense\\\_tracker.py
```

3. Open a terminal or command prompt in the folder containing the file.
4. Run:

```text
python expense\\\_tracker.py
```

## Non-Functional Requirements

### Usability

The program uses a simple numbered menu so that users can easily select an operation.

### Reliability

The program validates numerical input and handles invalid entries without terminating unexpectedly.

### Maintainability

The program is divided into separate functions, making individual operations easier to understand and modify.

### Performance

The program uses simple linear algorithms suitable for a small number of expense records.

## Limitations

\* Expenses are stored only while the program is running.
\* Data is not saved to a permanent file or database.
\* The application is designed for basic personal expense tracking.
